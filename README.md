# Nassim Benhabib — Portfolio

Bilingual static portfolio for GitHub Pages.

- English entry point: `index.html` / `en/index.html`
- French version: `fr/index.html`
- Three project pages per language under `en/projects` and `fr/projects`
- Shared styles and scripts under `assets/`
- No build, dependencies or backend required.

## Publish
Upload the contents of this folder to the repository root. In Settings → Pages, use “Deploy from a branch”, `main`, `/ (root)`.

## Edit
Edit the HTML for page content and `assets/style.css` for layout. Keep translations consistent.

The portrait currently uses a monogram. Replace `assets/portrait.svg` with your verified portrait, or change the image `src` in the three home pages.

The PDF is French. Project diagrams are conceptual illustrations, not experimental results.
